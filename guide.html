YOUR FIRST LAB WEBSITE

처음이어도 괜찮습니다.
이 순서대로 시작하세요.

이미 만들어진 홈페이지 파일을 GitHub에 올리고, GitHub Pages를 켜면 웹 주소가 생깁니다. 프로그램 설치나 코딩 없이 시작할 수 있습니다.

글·사진 수정하러 가기 ↗사용 설명서 내려받기 ↓

01 / EDIT

먼저 글과 사진을 내 연구실에 맞추기

  1. 콘텐츠 편집 화면을 엽니다.
  2. 왼쪽 메뉴에서 첫 화면·연구분야·교수님 소개·연락처를 선택하고 입력칸을 수정합니다. 교수님 경력과 학력은 항목을 추가하거나 삭제할 수 있습니다.
  3. 사진은 파일 선택으로 바꿉니다. 사진 용량은 1 MB 이하를 권장합니다. 사진은 수정 데이터에 함께 포함됩니다.
  4. 오른쪽 미리보기나 ↗ 새 창으로 결과를 확인합니다.
  5. 처음 배포할 때는 전체 사이트 ZIP ↓을 누릅니다. 압축을 풀면 GitHub에 올릴 파일들이 나옵니다.

수정본은 현재 브라우저에 임시 저장됩니다. 다른 사람의 홈페이지가 즉시 바뀌지는 않습니다. 파일을 내려받아 GitHub에 반영하는 단계가 필요합니다.

02 / CREATE

GitHub에 홈페이지 폴더 만들기

  1. github.com에 가입하고 로그인합니다.
  2. 오른쪽 위 + → New repository를 누릅니다. Repository는 홈페이지 파일을 보관하는 저장소입니다.
  3. Repository name에 lab-website처럼 영문 이름을 씁니다.
  4. 무료로 공개 홈페이지를 만들려면 Public을 선택합니다.
  5. Create repository를 누릅니다.

03 / UPLOAD

만든 파일 올리기

  1. 새 저장소에서 uploading an existing file을 누릅니다. 이미 파일이 있는 저장소는 Add file → Upload files를 누릅니다.
  2. ZIP을 먼저 풀고, 그 안의 파일과 assets 폴더를 모두 선택해 업로드 영역으로 끌어놓습니다. 압축 파일 자체를 올리면 안 됩니다.
  3. index.html이 저장소 첫 화면에 직접 보이도록 올립니다. 바깥 폴더가 하나 더 들어가지 않게 확인합니다.
  4. 아래의 Commit changes를 눌러 저장합니다.

정상적인 첫 화면
index.html, research.html, professor.html, data.js, assets/ 등이 저장소에서 바로 보입니다.

04 / PUBLISH

GitHub Pages 켜기

  1. 저장소 위쪽의 Settings → Pages로 들어갑니다.
  2. Build and deployment → Source를 Deploy from a branch로 선택합니다.
  3. Branch는 main, 폴더는 /(root)로 설정하고 Save를 누릅니다. 기본 브랜치 이름이 다르면 그 이름을 선택합니다.
  4. 배포가 끝나면 Pages 설정에 홈페이지 주소가 표시됩니다. Visit site로 확인합니다.

예시 주소
https://내아이디.github.io/lab-website/
교수님 페이지는 이 주소 뒤에 professor.html이 붙습니다.

GitHub 공식 안내: 사이트 만들기 · 배포 설정

05 / UPDATE

앞으로 내용을 바꾸는 방법

  1. 공개 홈페이지 맨 아래의 콘텐츠 편집 ↗을 누릅니다. 또는 홈페이지 주소 뒤에 editor.html을 붙입니다.
  2. 글·사진·약력을 수정하고 미리보기로 확인합니다.
  3. 배포용 data.js ↓를 누릅니다. 파일명이 data (1).js처럼 바뀌면 data.js로 고칩니다.
  4. GitHub 저장소에서 Add file → Upload files로 새 data.js를 올립니다. 같은 위치·같은 이름으로 덮어씁니다.
  5. Commit changes를 누르면 GitHub Pages가 다시 배포합니다. 반영 후 홈페이지를 새로고침합니다.

이 편집기는 로그인 없이 쓰는 개인 편집 도구입니다. 방문자가 수정해도 그 사람의 브라우저에만 저장됩니다. 실제 홈페이지를 바꾸려면 GitHub 저장소에 파일을 올릴 권한이 있어야 합니다.

수정할 수 있는 범위

하고 싶은 수정방법
문구·교수님 약력·사진·연락처콘텐츠 편집 화면에서 수정 → data.js 업로드
연구분야·학력·경력 항목 추가해당 항목의 추가 버튼 사용
포인트 색상기본 정보 → 포인트 색상
배치·글꼴·메뉴·페이지 추가이 대화에서 요청하거나 styles.css·app.js·HTML 수정

연구 항목의 위치를 크게 바꾸거나 새로운 연구실 소식·구성원·논문 목록을 추가하고 싶다면, 원하는 내용과 함께 수정을 요청하면 됩니다.

06 / FILES

파일은 각각 무슨 역할인가요?

파일역할
index.html연구실 첫 화면
research.html연구분야와 소개자료
professor.html교수님 소개·약력
contact.html연락처·위치
data.js전체 사이트의 글·사진·약력 데이터
editor.html글과 사진을 바꾸는 편집 화면
styles.css색상·배치·글자 크기
app.js페이지 구성과 메뉴·이미지 보기 동작
assets/사진·그림 파일

화면이 이상하면 확인해 주세요

  • 404가 보일 때: 배포가 완료됐는지, index.html이 배포 폴더 바로 안에 있는지 확인합니다.
  • 사진이나 글이 사라질 때: assets 폴더와 data.js를 함께 올렸는지 확인합니다.
  • 수정이 안 보일 때: 파일명이 data.js인지, GitHub의 업로드가 완료됐는지 확인한 뒤 강력 새로고침을 합니다.
  • 편집 미리보기가 안 될 때: 브라우저의 저장공간을 허용하고 사진 용량을 줄입니다. 컴퓨터에서 HTML 파일을 직접 연 상태보다 온라인 편집 화면을 권장합니다.
  • 전체 ZIP 다운로드가 안 될 때: 온라인 편집 화면을 이용하거나 data.js만 내려받아 기존 파일에 덮어씁니다.

첨부된 소개자료를 바탕으로 제작했습니다. 공개 전 교수님 직급·주요활동·호실 등 최신 정보를 편집 화면에서 확인해 주세요.
